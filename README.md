# Foliage DD

Tax due diligence workspace for entity and asset deals: data room, request lists, issues, REIT tests, and project users.

Live site: [foliage-dd.com](https://foliage-dd.com)

## Stack

- TanStack Start / React
- Postgres (Neon in production)
- Better Auth

## Scripts

```bash
npm install
npm run dev
npm run build
```
